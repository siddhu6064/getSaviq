## Scope calls (read before reviewing the diffs)

- **#12 Multi-currency** is scoped to **display/formatting only**: a per-profile
  currency preference that changes the symbol/format everywhere (`formatCurrency`
  currently hardcodes USD at every call site despite already accepting a currency
  param). This does **not** add FX conversion or mixed-currency-per-transaction —
  that's a materially bigger feature (rate API, conversion pipeline) and belongs in
  the v2 "real" multi-currency item, not this quick-win pass.
- **#6 Cash-flow forecast** is scoped to a **30-day day-by-day projected-balance
  list** (current balance + upcoming bill due dates + recurring expenses), not a
  full custom calendar grid. Delivers the actual value (see a shortfall coming)
  without the extra UI-build cost of a grid component.
- **#7 CSV import** round-trips the existing export format exactly (`Date, Type,
Description, Amount, Category, Payment Method, Merchant, Notes`), resolving
  category/payment-method names to IDs (creating them if missing, same as manual
  entry would).
